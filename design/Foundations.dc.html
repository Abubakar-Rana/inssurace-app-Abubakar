Rules
One accent, two jobs. Orange means an action you can take, or unread. If it appears anywhere else, it is decoration — remove it.
State is a heading, not a colour. Needs you · Waiting on someone else · Done. The reviewer's question is answered by where a row sits, before they read it.
Abstention is not an error. needsMatch gets no red and no warning icon — it is the system declining to guess, and it sits at the top because it is the work.
Rows are rows. A hairline between them, no card, no shadow, no radius. Shadow is for things that float: dialogs and the document.
Volume is a tab, not a scroll. Needs you / Waiting / Done / All carry their counts in the tab bar, so the three questions are answered at 12 requests and at 1,200 without moving. Group headings stick while the list scrolls.
Finished work gets one line. A done request is for finding, not reading: 44px, single line, grouped by day, with search as the instrument and explicit paging — never infinite scroll, which hides how much you have not seen.
No invented metrics. Counts come from rows that exist. The old "Avg. handle time 38s" was hardcoded and is gone.
